# Pause

A countdown page for my iPhone. When I open Instagram, Facebook, X or Reddit, an iOS Shortcut opens this page with my reminders, and the button into the app unlocks after 10 seconds of looking at them.

The page holds no data. The Shortcut reads a reminders file that my Mac writes to iCloud Drive and passes it in the part of the link after `#`, which the browser never sends to the server.
